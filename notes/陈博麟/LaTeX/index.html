    LaTeX 数学公式速查表¶

    适用环境： Typora / MathJax 数学模式
    阅读方式： 按用途分区；每个分区独立成表，优先列出符号、可复制命令和用途。
    提示： 命令请复制到数学环境中使用，例如 $ \alpha $ 或 $$ \alpha $$。表中反引号内的命令均使用单个反斜杠。

    1. Typora 公式基础¶

    用途 输入方式 示例
    行内公式 $...$ $a+b=c$
    独立公式 $$...$$ $$a+b=c$$
    行内公式（替代） \(...\) \(a+b=c\)
    独立公式（替代） \[...\] \[a+b=c\]
    公式内普通文字 \text{...} \text{where }x>0
    百分号字符 \% 50\%
    下划线字符 \_ file\_name
    花括号字符 \{、\} \{1,2,3\}

    基本规则

    规则 正确写法 说明
    多字符上标 x^{n+1} 上标内容用 {} 包起来
    多字符下标 a_{ij} 下标内容用 {} 包起来
    公式中插入文字 \text{当 }x>0 普通文字使用 \text{}
    微分符号 \,\mathrm{d}x 常用正体 d 表示微分
    公式中的空格 \quad 普通空格通常会被忽略

    2. 上下标、分数与根式¶

    效果 LaTeX 命令 用途／说明
    上标 x^2 平方
    下标 x_i 下标
    多字符上标 x^{10} 多位指数
    多字符下标 x_{ij} 多字符索引
    分数 \frac{a}{b} 常规分数
    大分数 \dfrac{a}{b} 显示风格，通常更大
    小分数 \tfrac{a}{b} 文本风格，通常更紧凑
    平方根 \sqrt{x} 平方根
    n 次根 \sqrt[n]{x} n 次方根
    组合数 \binom{n}{k} 二项式系数
    上方标注 \overset{a}{=} 在等号上方加标注
    下方标注 \underset{n\to\infty}{\lim} 在符号下方加标注
    上下标注 \overset{a}{\underset{b}{=}} 同时添加上下标注

    10. 求和、连乘与极限¶

    用途 命令 说明
    求和 \sum_{i=1}^{n}a_i 从 i=1 加到 n
    连乘 \prod_{i=1}^{n}a_i 从 i=1 乘到 n
    大并集 \bigcup_{i=1}^{n}A_i 多个集合的并
    大交集 \bigcap_{i=1}^{n}A_i 多个集合的交
    极限 \lim_{x\to a}f(x) x 趋近 a
    左极限 \lim_{x\to a^-}f(x) 从左侧趋近
    右极限 \lim_{x\to a^+}f(x) 从右侧趋近
    无穷远极限 \lim_{x\to\infty}f(x) x 趋于无穷

    下极限 \liminf_{n\to\infty}a_n lim inf
    上确界 \sup A 最小上界
    下确界 \inf A 最大下界
    最大值 \max_{x\in A}f(x) 最大值
    最小值 \min_{x\in A}f(x) 最小值

    11.1 导数与微分¶

    用途 命令 说明

    n 阶导数 f^{(n)}(x) n 阶导数
