# TLCP
## 密钥计算
主密钥计算
![f07b56700b0dfc11f584343cbac8364b](assets/07f4d12f94849fb94e5107590451c7be.png)
工作密钥计算
![ae860cad9e333a8798348c42e2601da4](assets/ae860cad9e333a8798348c42e2601da4.png)
非可鉴别加密模式工作密钥切分双向两个32字节mac，两个16字节加密密钥，一般不使用iv
可鉴别加密模式切分双向2个16字节加密密钥及双向两个4字节iv的起始值（用做后续gcm模式下ctr计数器的前4个字节）
