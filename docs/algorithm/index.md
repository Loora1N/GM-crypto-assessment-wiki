# 密码算法

本章节整理算法原理、参数说明、实现笔记和学习示例。正式文章按以下二级分类建立独立目录；新增文章后，将实际文件路径加入 `mkdocs.yml` 的相应分类。

## 对称密码算法

收录 SM4 等对称密码算法的原理、工作模式和实现笔记。文章目录为 `docs/algorithm/对称密码算法/文章名称/`。

## 非对称密码算法

收录 SM2、RSA 等非对称密码算法的原理、参数和接口笔记。文章目录为 `docs/algorithm/非对称密码算法/文章名称/`。

## 杂凑算法

收录 SM3 等杂凑算法的原理、计算示例和学习笔记。文章目录为 `docs/algorithm/杂凑算法/文章名称/`。
