# 密码协议

本章节整理协议流程、报文结构、参数说明和应用笔记。正式文章按以下二级分类建立独立目录。

## 安全传输协议

收录 TLS、TLCP 等协议的流程与报文笔记。文章目录为 `docs/protocol/安全传输协议/文章名称/`。

## 认证协议

收录身份认证、证书认证等协议的学习笔记。文章目录为 `docs/protocol/认证协议/文章名称/`。

## 密钥交换协议

收录密钥交换、协商和相关流程笔记。文章目录为 `docs/protocol/密钥交换协议/文章名称/`。

## 维护入口

新增或修改文章时，请按[快速开始](../maintenance/快速开始/快速开始.md)完成目录创建、导航登记、本地检查和 Git 提交。
