    数论相关¶

    费马小定理¶

    若p是素数，a是正整数且不能被p整除，则有：

    \[ a^{p-1} \bmod p =1 \]

    欧拉定理¶

    欧拉函数φ(n)¶

    • φ(n)是比n小且与n互素的正整数的个数，即模n的缩剩余系中元素之个数
    • 定理：p和q是素数，若\(n = p * q\)，\(φ(n)=φ(p)*φ(q)=(p-1)*(q-1)\)

    欧拉定理¶

    对于任意互质的a和n有：

    \[ a^{φ(n)} \equiv 1\pmod n \]
    • 费马小定理可以看作欧拉定理n为素数时的特殊情况，n为素数时，有
    \[ φ(n) = n - 1 \]

    则根据欧拉定理：

    \[ a^{n-1} \equiv 1 \pmod n \]

    泛杂凑函数定义¶

    泛杂凑函数亦称为通用哈希函数（Universal HASH Function）。通用哈希函数描述的不是一个具体的hash函数，而是一个hash函数的集合，即一个满足特定条件的hash函数族。

    通用哈希函数的特定条件如下：

    假设存在hash函数族如下：

    \[ H = \{h1, h2,h3,...,h_k\} \]

    \(k\)表示具体的hash函数的总数。且对于其中每一个hash函数\(h\)，都能够将输入映射到同一个输出空间

    设\(H\)这一族哈希函数的映射输入\(x,y\in U: [0,n-1]\)。泛杂凑函数的输入一般为有限域

    对于任意选取的\(x\ne y\), 如果从函数族 \(H\) 中均匀随机选择一个函数 \(h\)，有：

    \[ \Pr_{h\in H}[h(x)\ne h(y)] \le \frac{1}{m} \]

    那么，\(H\)即为一个泛杂凑函数。

    • \(\Pr_{h\in H}[h(x)\ne h(y)]\)，两个杂凑值不相等的概率
    • \(m\)，杂凑输出结果的范围大小

    这意味着，对于任意两个不同的输入，随机选取h的碰撞概率不高于 1/m

    这里的随机性来源于随机选择哈希函数h，而不是随机选择输入

    有限域乘法¶

    有限域（Finite Field，也称Galois Field）

    \[ GF(2^{128}) \]

    \(GF\)为有限域的缩写，\(2^{128}\)用来表示有限域的元素个数

    有限域的元素表示¶

    对于有限域\(GF(2^{128})\)，任何一个元素都可以用128位的01串来表示,例如

    \[ 0101...1100|_{128} \]

    但这里的01并不直接表示01组成的整数，其在做乘法运算时，本质是作为高次多项式的系数。

    对于一个由01组成的二进制串来说，假设有限域的大小为\(2^m\)（即\(GF(2^m)\)），二进制串的每一位用\(a_i\)，则二进制数形式为：

    \[ a_0a_1a_2...a_{m-1}a_m \]

    若对应到多项式系数，则可表示为：

    \[ a_mx^m + a_{m-1}x^{m-1}+...+a_2m^2+a_1m^1 \]

    有限域乘法¶

    做有限域乘法是，本质上对\(GF(2^m)\)这个有限域上的多项式乘法，同时为了保证多项式的乘法结果依然在有限域内，需要选择一个不可约多项式称为\(p(x)\)，多项式乘法的结果将变成\(mod(p(x))\)有限域下的结果。

    \(p(x)\)必须是一个\(m\)次的不可约多项式

    为了方便理解，这里我们举例有限域场景为\(GF(2^{4})\)

    设有两个变量\(A = 0101, B = 1110\)

    选择有限域的不可约多项式\(p(x)\)

    \[ p(x) = x^4 + x +1 \]

    对于有限域\(GF(2^4)\)，四次多项式如\(p(x)\)所示，以\(x^4\)起

    计算\(A \otimes B\),如下:

    首先用多项式形式的表示AB

    \[ A = x^2 + 1\\ B = x^3 + x^2 + x \]

    对A和B做多项式乘法，

    \[ A * B = (x^2 + 1) * (x^3 + x^2 +x)\\ =x^5 + x^4 + 2*x^3 + x^2 + x \]

    显然这个多项式的表达，超出了\(GF(2^4)\)的范围，这是我们要考虑使用不可约多项式\(p(x)\)

    我们本质是计算 \(A*B\ mod\ p(x)\)

    \[ p(x) = x^4 + x + 1 \]

    由上式，我们可以推导出如下这些式子:

    \[ x^4 \equiv x + 1 (mod\ p(x))\\ x^5 \equiv x^2 + x (mod\ p(x))\\ .....\\ ..... \]

    就可以将高次项转换为有限域内的低次项,带入上式中可以得到

    \[ 原式 \equiv 2*x^3 + 2*x^2 + 3*x + 1 (mod\ p(x))\\ \equiv x + 1 (mod\ p(x)) \]

    对应结果为\(0011\)

    由于我们是在\(GF(2^4)\)下，也就是系数模2域，则有\(0 \equiv a + a (mod\ p(x))\)
